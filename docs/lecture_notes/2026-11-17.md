# 11/17 1차 컨설팅 정리

교수님 공지와 컨설팅 때 들은 내용 중 **우리 작업에 영향이 있는 것만** 모았다. 평가 기준 전체는 [evaluation.md](../evaluation.md).

## 1. 지켜야 할 규칙

| 항목 | 규칙 | 우리 상태 |
|---|---|---|
| 판단 | AV 판단은 **학습만**. 보조 규칙, 안전장치, 규칙·MLP로 시나리오 고르기 모두 안 됨 | AV 안전 제어 전부 해제 (`speedMode=0`) ✅ |
| 보상 | 항은 **꼭 필요한 것만**, 조정은 가중치로. 신호 관련 항은 하나면 충분 | 신호 항 1개 (`red_light_penalty`), 가중치만 탐색 중 ✅ |
| 경로 | 큰 틀의 경로는 줘도 됨. **어느 차선으로 갈지 같은 세밀한 정보는 안 됨** | 경로 기준 차로 관측 제거 (환경 v2) ✅ |
| 칼럼 타입 | 문자열 대신 숫자. 신호는 0 / 0.5 / 1, **신호등마다 독립 칼럼** | 신호 6개 × (색, 현시, 남은 시간) ✅ |
| 칼럼 범위 | State만 보고 도로 상황을 다시 그릴 수 있으면 충분. 47개 정도까지 괜찮음 | 39개, AV 반경 100 m 차량 정보 포함 ✅ |
| 미래 예측 | 관측 정보로 수학적으로 계산하는 건 괜찮음 | – |

## 2. 학습할 때 기억할 것

- **원하는 대로 안 움직이면 보상부터 본다.** 그 행동이 보상 관점에서 유리한지 확인한다.
- **너무 잘 되면 의심한다.** 교통이 충분한지, AV 주변에 차가 충분한지, 정속 주행만 하는데 주변 차가 피해 준 건 아닌지 확인한다. 가감속을 합리적으로 하는지도 본다.
- **난이도는 차츰 올린다.** 쉬운 환경에서 먼저 성공하고 넓혀 간다. 사고가 안 나는 게 1순위다.
- **시드 견고성은 강점이 된다.** 평균적으로 잘 되는 걸 목표로 한다.
- **모방학습(BC)이 안 되면 데이터를 본다.** 데이터의 범위, 양, 주행 품질을 다시 검토한다.

## 3. 아직 결정 안 한 것 (2차 컨설팅 질문 후보)

- 사거리 우회전: 빨간불에서 일시정지 후 우회전(SUMO 신호 `s`)을 넣을지, 넣으면 AV도 배워야 하는지
- 회전교차로 혼잡: 기본 교통에서 거의 안 막힘 → 양보 성향 조정이나 교통량 추가가 괜찮은지
- 막힘 감점(`blocked_penalty`): 차로 변경을 배우게 하려고 다시 켜는 게 "보상 최소" 원칙에 맞는지

## 4. 2차 컨설팅 (13조 11/24) 자료

순서는 공지대로 한다. 시간이 빠듯하니 질문을 미리 정리해 간다.

1. 도로 구조 (시뮬레이션 캡처나 도로 구조 그림)
2. 데이터 칼럼 구성 표
3. 질문 목록

학습된 AV가 나오는 10–20초 주행 영상을 넣으면 좋다.
