## 3. 중간발표 (11/10) — 3분

목적은 점수가 아니라 **방향 점검과 공유**. 교수·조교만 평가. "밑그림이 잘못되면 뒤에 아무리 잘해도 소용없다" — **도로 선정과 차량 간 상호작용**을 집중해서 본다.

| 반드시 들어갈 내용 | 구체적으로 |
|---|---|
| ① 선정한 실제 도로 | 어느 지역인지, 지도·실제 사진 |
| ② 도로의 구조적 특징 | 삼거리/사거리/오거리/회전교차로/합류/분기/다중차선/차로감소/비정형 교차로 등 **모듈의 조합으로 설명** |
| ③ 왜 흥미로운가 | 자율주행 의사결정 문제로서 의미 있는 이유를 설득 |
| ④ 구체적인 상호작용 | "직진 ↔ 좌회전", "합류 ↔ 본선", "느린 차 추월"처럼 **어느 구간에서 무엇이** |
| ⑤ 데이터 형태 | 수집할 컬럼 구성 |
| ⑥ 역할 분담 | 한 페이지. 누가 무엇을 맡는지 |

> **교수님 힌트: "눈치 게임"이 많을수록 AI에게 어렵다.** 여러 방향에서 차량이 동시에 진입해 서로 양보하고 끼어들어야 하는 구간일수록 자율주행 문제로서 가치가 크다. 유명한 장소라는 것만으로는 부족하다.

### 발표 운영 규칙 (엄격)
- **3분 초과 시 즉시 중단**
- 발표 자료는 **과제함에 제출** → 교수님이 일괄 다운로드한 파일로 진행. **USB 불가**
- **제출 마감 = 수업 시작 15분 전**
- 슬라이드·동영상 확인은 수업 10분 전 강의실 컴퓨터에서 가능 (줄 서서)
- 발표 시작 후 파일 문제로 지체하면 **그 시간만큼 발표 시간에서 차감**
- 발표자는 자유. 짧은 발표에서 발표자가 자주 바뀌면 집중력이 떨어짐
- **슬라이드를 많이 만들지 말 것.** 엔지니어링 발표는 화려함이 아니라 정보 전달

## 4. 최종발표 (11/28) — 13분 내외
- 13:00~19:00, 6시간 필참
- 팀당 13분 예상 (±2~3분, 중간발표 후 확정)
- 순서는 팀 번호가 아니라 **비슷한 주제끼리 묶은 세션**
- **학생 상호평가(피어 평가) 있음**

| 구분 | 내용 |
|---|---|
| 환경 | 선택한 도로, 도로 구조, 일반 차량 구성 |
| AV 설계 | Observation / Action / Reward, 학습 방법 |
| 성능 | **충돌률, 보상 값, 목적지 완주 여부** |
| 주행 영상 | **30초 이상 필수.** 도로 구조 + 일반 차량 + AV + 상호작용 + 완주가 드러나야 함 |
| 데이터 | 수집한 데이터 설명 |
| 문제 해결 | 진행 중 발견한 문제와 해결 과정 |

### 통과해야 하는 기준선
| 기준 | 설명 |
|---|---|
| 충돌률 5% 이하 | 계속 들이받으면 "만들었다"고 보기 어렵다 |
| 목적지 완주 | 문제없이 끝까지 주행 |
| 비정상 동작 없음 | 엉뚱한 길로 빠지거나, 사고는 없는데 **혼자 가만히 서 있는 상태 = 의미 없음** |
| 충분한 일반 차량 | AV 혼자 달리는 건 의미 없음. **의도한 구간에서 상호작용이 실제로 발생**해야 함 |

- 차량 대수·밀도의 **숫자 기준은 없음** (도로 구조마다 의미가 달라서). **영상으로 보여주고 납득시키면 됨.** 친구들도 같은 삽질을 해본 사람들이라 꼼수는 통하지 않음.
- 도로 형태 제약 없음 (순환형·개방형 모두 가능)
- **신호등 추가 가능. 단, 추가했다면 State 컬럼에 신호 상태도 넣어야** 데이터가 의미를 가짐

## 6. 데이터 — 가장 중요하게 보는 항목
> "인공지능은 데이터가 8할입니다. 도로를 잘 만들고 좋은 기술을 써도 데이터 수집이 엉망이면 아무것도 사용 못 합니다."

| 규칙 | 내용 |
|---|---|
| **조교 공개 컬럼** | **반드시 포함, 삭제 불가.** 중복처럼 보여도 이유가 있어서 넣은 것 |
| 컬럼 추가 | 자유. **왜 추가했는지 설명하면 차별점** |
| 불필요한 컬럼 | 지양. 예: 내 절대속도 + 옆 차 절대속도가 있으면 상대속도는 계산 가능 → 3개 다 넣을 필요 없음 |
| 데이터 규모 | 정리본 표기 "샘플 수 107 수준" — **10⁷(천만)의 위첨자가 깨진 것으로 추정, 확인 필요** |

용어: 컬럼(열) = 수집 항목, 행 = 데이터 샘플 하나
