## 코드 작업 시작 방법 (정해지면 채우기)

수업 코드는 계속 업데이트되므로 지금은 이 저장소에 넣지 않았다. 코드 작업을 시작할 때 아래 중 하나로 정한다.

- **안 1.** 시작 시점의 수업 코드를 이 저장소에 복사하고, 이후 수업 업데이트는 필요한 부분만 골라 반영
- **안 2.** 우리가 고친 파일만 이 저장소에 두고, 수업 코드 폴더에 덮어써서 실행
