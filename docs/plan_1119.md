# 11/19 오후 작업 계획 (자동 연속 실행용)

각 단계는 결과를 보고 다음 단계로 넘어간다. 끝났는데 문제가 보이면 원인부터 확정하고(재생·갈래 비교·관측 바꿔 끼우기), 고친 뒤 다시 평가한다.
모델 교체 기준 (셋 다 만족해야 `models/`에 올림):
1. 시드 1000–1199(200개): 충돌 < 5%, 완주 ≥ 95%
2. 신호 앞 정지 위치가 r_s5 10만 수준 이상 (출발지·정류장 앞 서부로에서 멀리 정지 거의 없음, 정문 앞은 개선)
3. 급제동·급가속이 지금(3.0/km, 10–13/km)보다 나빠지지 않음

## A. 1차 완성본 확정 (지금 진행 중)
1. 후보 평가: r_s11(빨간불 대기 감점 + 진행 방향 관측), r_s11s(+ 가까운 앞차 음수 거리), r_s5+r_s8 평균 → `results/eval_s11.txt`
2. 시간초과 판별: r_s8을 제한 시간 1200초로 평가 → 시간만 더 주면 도착하는지, 갇혀 서 있는지 (`results/diag_1119/s8_100k_long.txt`)
3. 기준을 넘는 모델을 시드 200개 + 주행 품질로 확정 → `models/`에 1차 완성본으로 올리고 전달 문서 갱신

## B. 남은 주행 문제
1. 정문 앞 멀리 정차: 원인 확정(다가가는 이득 +0.5로 작음, 3차로 맨 왼쪽 관측일 때만 멈춤). 대책 r_s11. 안 되면 대기 감점 크기 조정
2. 앞차 뒤 정지 간격: 지금 설계상 앞차 8 m 뒤까지만 다가감. 실제 간격을 재고, 멀면 '둘 다 서 있을 때만' 기준 4 m 시험
3. 남은 충돌: 교차로별 실패 재생 → 관측 구멍이면 관측 수정, 판단이면 그 지점 출발 섞기
4. 급가속·급감속: 이유 없는 감속 위치 분류 후, 이어서 학습용 승차감 감점(0.5, 문턱 0.7) 재시험 — r_s5j에서는 정지 위치가 나빠졌으므로 정지 위치 확정 뒤에

## C. 교통 (골목·회전교차로 상호작용, 정체 없이)
1. 골목 오거리 흐름 1.6배, 율전로 합류 1.3배, 율전로98번길 좌회전 교차 흐름(ia_l98) 추가 — `traffic.py`, `regen_interaction.py` (원본 미적용)
2. 복사본에서 정체·순간이동·통과 대수 측정 → 원본 적용 → `view_road.py --nogui --seconds 120`
3. 새 교통(환경 v4)에서 1차 완성본 평가 → 섞어서 이어서 학습 → 시드 200개 재확인. v3 결과는 따로 보관(비교 끊김 명시)

## D. 견고성
1. 다른 시드 묶음(1200–1399) 평가
2. 난이도 단계(level_hard, difficulty_mix) 평가와 섞어 학습

## E. 발표·제출 어필
1. "관측 구멍을 실측으로 찾아 고친 과정": 가까운 앞차 '없음' 처리(수업 코드), 교차로 안 교차 차량, 상태 파일 libsumo 재현 버그 — 재생 장면 캡처와 전후 수치
2. 평가 방법: 시드 200개, 재현성(새 clone 확인), 체크포인트 가중치 평균
3. 상호작용 장면 영상: 골목 오거리 양보, 회전교차로 진입, 정문 좌회전, 서부로 합류
4. 데이터 컬럼: 양보 위반 이벤트(event.yield_violation) 추가 검토, 컬럼 근거 표
5. 보상 항 근거 표 (항목·크기·도입 이유·측정 근거)
6. 마지막에 최종 설정으로 처음부터 한 번 학습해 이어서 학습한 모델과 비교 (팀원 의견)
