# 시행착오 정리 (문제별, 11/20 기준)

`experiments.md`는 날짜순 기록이고, 이 문서는 그 기록을 **문제별로 묶어 다음 판단에 쓰도록** 정리한 것이다.
새 실험을 시작하기 전에 같은 문제 칸을 먼저 보고, 끝나면 결과를 같은 칸에 한 줄 더한다. 발표의 "시행착오·개선 과정" 자료로도 쓴다.

## 평가 방법에서 배운 것

| 배운 것 | 근거 |
|---|---|
| 시드 40개 선별은 쓸 수 없다 | r_s16 40개 39/0/1 → 200개 180/17/3 |
| 시드 200개에서 충돌 3~5건 차이는 잡음 | 같은 정책(낮은 lr 2.5만 스텝)도 ±4%p. s8+r_s21 가중치 평균: 1200–1399 충돌 7(s8 10) → 1400–1599 15(s8 14) |
| 고른 시드로 보고하면 낙관적 | r_s8: 고른 시드 1000–1199 충돌 2.5%, 새 시드 400개 6.0% |
| 원칙 | 선택은 1000–1199, 보고는 1200–1599(400개), 같은 시드끼리 비교, 실패 **위치**까지 비교 |
| libsumo 상태 파일 재현성 | 상태 파일을 sumo CLI `--save-state.times`로 만들어야 같은 시드가 같은 결과 |
| 처음부터 학습은 재현 안 됨 | 같은 설정 77~82% vs 이어서 학습 94% → 좋은 모델에서 이어서 학습 |
| 제한 시간 | 600·800초 시간초과는 교통 많은 시드에서 느린 것(갇힘 아님) → 1200초 |

## 문제별

### 1. 앞차 간격 (멀리 섬·멀리 따라감) — 미해결, 원인 확정 단계
- 측정 (11/20, r_s8 시드 12개 vs 같은 시뮬레이션 배경 승용차): 둘 다 정지 간격 중앙 **26.8 m vs 2.5 m**, 50 m 안 추종 시간간격 **6.5 s vs 1.6 s**. AV는 50 m 안 추종 자체가 거의 없음
- 원인 ① 보상: 멀리 있는 비용이 거의 없음(달리며 따라갈 때 0, 서 있을 때 정차 감점 0.01~0.02/스텝), 가까운 비용은 −0.1/스텝(6 m, 2초)과 충돌 −5
- 원인 ② 관측 축척 (11/20 측정): 앞차 거리 입력은 거리/50 m라 0~5 m가 입력 0~0.1. r_s8에 서 있는 앞차 뒤 상태 28개에서 거리 입력만 바꾸면 **가속 명령이 1 m당 약 0.02만 변함**(20 m → 0 m 전체가 −0.4). 0 m와 2 m를 거의 구분 못 함
- 시도와 결과
  - queue_fix (대기열에서 간격 감점 되돌림): 정지 간격 41 m → 16 m. 대신 0.5 m/s 미만으로 기어가는 것이 공짜가 되어 저속 추돌
  - queue_approach (세울 수 있는 속도면 면제, r_s13·r_s16): 저속 추돌 증가, 495951447 9건
  - queue_strict (1.5 m 안 움직이면 되돌림 안 함, r_s22): 충돌 5→16→27. 11/20 재생: 늘어난 충돌은 495951447 8/15건이고, **교차로 출구에 선 앞차에 거리 입력 0.00인 채로 가속 +0.1**
- 교훈: 보상만 바꿔 AV를 앞차에 더 다가가게 하면 매번 충돌이 늘었다. 원인 ②(가까운 거리를 구분 못 함) 때문이라는 해석이 측정과 맞는다. → **관측을 먼저 고치고(가까운 범위 해상도, 필요한 감속도 같은 물리량), 보상(목표 간격 하나로 땜질 항 대체)은 그 다음**

### 2. 신호 앞 멀리 정차 (특히 정문 앞 좌회전 차로 40~50 m) — 미해결
- 갈래 비교: 다가가는 쪽이 할인 보상 +0.14~+1.0, 가치 함수도 가까운 쪽을 높게 봄 → 보상·가치는 '다가가라', 정책만 안 바뀜
- 관측 바꿔 끼우기: 차로 연결성을 1차로처럼 바꾸면 진행. 진행 방향 관측 추가(r_s14)는 영향 ±0.04(안 씀)
- 효과 없던 것: 빨간불 접근 보상, 빨간불 대기 감점 0.05/0.1/0.2, 정문 앞 출발 비중 40%, 투입 시각 무작위 0~90초
- 대기 감점을 키우면 다른 곳 충돌 증가 (문제 1과 같은 구조로 추정)
- 팀원 local_b (mingi/local-b): 정지선까지 거리·필요 감속 관측 3개 + 일월로 한 도로 정지 보상, 첫 층 새 3열만 학습. 관측 쪽은 일반적이라 활용 가치 있음, 보상은 한 도로 전용

### 3. 495951447 (서부로 합류 교차로) 충돌
- 원인: 출구 차로 시작점에 선 합류 차 뒤로 교차로에 들어가 그 안에서 추돌
- 관측 구멍 수정(obs_close_fix: 거리가 minGap보다 작으면 '앞차 없음'이 되던 것) → r_s8
- 꼬리물기 감점(box_penalty 2): r_s19·r_s21에서 4~9건 → 1건. 그러나 r_s22에서 다시 8건 → 감점만으로는 약함, 문제 1 원인 ②와 같은 계열

### 4. 495951808 좌회전 진입 — 미해결
- 교차 차량 TTC 1~2초인데 3.5 m/s로 진입, 교차로 안에서 양보 표시가 0으로 바뀌며 가속
- obs_inside_fix(교차로 안 교차 차량)로 4→3건. 새 시드 400개 기준 6건

### 5. 대기열 저속 추돌
- 0.2~1.8 m/s로 기어가다 닿음, 거리 입력 0.00~0.07, 가속 명령 −0.01~+0.12 → 문제 1 원인 ②와 같음
