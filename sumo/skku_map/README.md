# 성균관대역 일대 SUMO 도로망 (skku_map)

성균관대역 사거리(원점 0,0, x 동쪽·y 북쪽, 단위 m)를 중심으로 율전동·천천동·정자동 일대와
봉담과천로(의왕TG, 축소판 일자 고속도로 → 서부로에 바로 이어짐)를 SUMO로 만든 것. OSM을 바탕으로 카카오맵 길찾기·위성사진으로 확인한 값을 덧입혔다.

## 보기
- 바탕화면 `성대역 SUMO` 바로가기, 또는 `run_skku.bat` 더블클릭
  - 1: 차량·버스 1시간 시뮬레이션 (기본, `view_skku.py`) / 2: 도로만 / 3: 도로망 다시 만들기 후 시뮬레이션
  - 직접 실행: `python -X utf8 view_skku.py` (sumo-gui + TraCI). `sumo-gui -c skku.sumocfg`로 열어도 되지만 아래층 차가 옅어지지 않는다
- 층 표현 (지도식): 겹치는 곳에서는 높이(z)가 낮은 도로가 뒤에, 낮은 층의 도로와 차는 옅게 보인다
  - 고가(+6 m): 불투명 남색 면 + 진한 테두리 + 그림자. 고가 양옆 지상 서부로는 고가에서 3 m 띄워 그렸다 (실제보다 조금 바깥)
  - 지하차도(-6 m): 옅은 회색 면이 지상 도로·교차로 면 밑에, 차선은 점선(숨은 선)으로 위에 비쳐 보임
  - 아래층 차(지하차도, 고가 밑 지상·주차장): `view_skku.py`가 TraCI로 반투명하게 칠함 (sumo-gui는 차를 항상 맨 위에 그린다)
  - sumo-gui는 도로망을 한 층에 그려서, 고가·지하차도는 투명하게 두고 도형(skku.add.xml의 via_*, under_*)으로 직접 그린다
- 고가 밑 공영주차장 3곳: 주차하러 오는 차(vClass taxi)만 통로를 쓴다. 입구·출구는 `build.py`의 `lots` 주석 참고
- 한 스텝 0.2초. Delay(ms)는 한 스텝마다 쉬는 시간 → 100이면 실제의 2배 빠르기, 200이면 실제 속도

## 다시 만들기
```
python -X utf8 build.py            # 만들고 1시간 3회(seed 42, 1, 2) 점검
python -X utf8 build.py --no-check
python -X utf8 route_check.py      # 카카오 길찾기 결과와 SUMO 경로 비교
```

## 파일
| 파일 | 하는 일 |
|---|---|
| `build.py` | 전체 순서: OSM 잘라오기 → netconvert → 수정(신호·유턴·주차장·고속도로·높이) → 교통 |
| `osm_clip.py` | 구현 범위 자르기, 카카오로 확인한 일방통행·차로 수(`LANES_VERIFIED`), 분리 도로 붙이기, 작은 골목 빼기 |
| `parking.py` | 고가 밑 공영주차장 3곳·교내/역 주변 주차장의 주차면과 주차 차량 (빈 칸이 있는 구역에만 배정) |
| `view_skku.py` | 시뮬레이션 보기: sumo-gui + TraCI, 아래층 차를 반투명하게 |
| `bus_lines.py`, `bus_kakao.json` | 카카오맵 실제 버스 노선 17개를 도로망에 맞춰 정류장·운행 생성 |
| `background.py` | 배경(건물·아파트 단지·공원·물·철도)과 지명 글자 (sumo-gui 글꼴에 한글이 없어 영어) |
| `kakao_verified.txt`, `kakao_routes.txt` | 길찾기로 확인한 일방통행·양방향 근거 |
| `WORKLOG.md` | 작업 기록, 위성사진 차로 조사 결과 |

## 확인한 것과 가정한 것
- 확인(카카오 길찾기·위성사진·로드뷰): 일방통행, 큰길 차로 수(서부로·덕영대로·화산로·일월로·정자천로 등),
  막힌 캠퍼스 문(후문·서쪽 문), 버스 노선·정류장, 의왕TG·IC 순서
- 사용자 지정: 사거리 신호(차량 동시 녹색 70초 → 황색 3초 → 보행자 동시신호 45초), 사거리 북쪽 방향 좌회전 금지
- 가정: 사거리 외 교차로 신호 시간(SUMO 기본 생성), 교통량, 주차 시간, 요금소 부스 수(한 방향 10개)
