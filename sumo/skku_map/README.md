# 성균관대역 일대 SUMO 도로망 (skku_map)

성균관대역 사거리(원점 0,0, x 동쪽·y 북쪽, 단위 m)를 중심으로 율전동·천천동·정자동 일대와
봉담과천로(의왕TG, 축소판 일자 고속도로 → 서부로에 바로 이어짐)를 SUMO로 만든 것. OSM을 바탕으로 카카오맵 길찾기·위성사진으로 확인한 값을 덧입혔다.

## 보기
- 바탕화면 `성대역 SUMO` 바로가기, 또는 `run_skku.bat` 더블클릭
  - 1: 차량·버스 1시간 시뮬레이션 (기본, `view_skku.py`) / 2: 도로만 / 3: 도로망 다시 만들기 후 시뮬레이션
  - 직접 실행: `python -X utf8 view_skku.py` (sumo-gui + TraCI). `sumo-gui -c skku.sumocfg`로 열어도 되지만 아래층 차가 옅어지지 않는다
- 층 표현 (지도식): 겹치는 곳에서는 높이(z)가 낮은 도로가 뒤에, 낮은 층의 도로와 차는 옅게 보인다
  - 고가(+6 m): 불투명 남색 면 + 진한 테두리 + 그림자. 고가 양옆 지상 서부로는 고가에서 3 m(주차장 띠가 있는 곳은 약 12 m) 띄워 그렸다 (실제보다 바깥)
  - 지하차도(-6 m): 옅은 회색 면이 지상 도로·교차로 면 밑에, 차선은 점선(숨은 선)으로 위에 비쳐 보임
  - 아래층 차(지하차도, 고가 밑 지상·주차장): `view_skku.py`가 TraCI로 반투명하게 칠함 (sumo-gui는 차를 항상 맨 위에 그린다)
  - sumo-gui는 도로망을 한 층에 그려서, 고가·지하차도는 투명하게 두고 도형(skku.add.xml의 via_*, under_*)으로 직접 그린다
- 고가 밑 공영주차장 3곳: 화면에서 고가와 구분되도록 고가 바깥 양옆(도로 쪽) 띠에 통로 + 직각 주차 칸으로 그렸다 (실제는 고가 밑).
  주차하러 오는 차(vClass taxi)만 통로를 쓴다. 입구·출구는 `build.py`의 `lots` 주석 참고
- 한 스텝 0.2초. Delay(ms)는 한 스텝마다 쉬는 시간 → 100이면 실제의 2배 빠르기, 200이면 실제 속도

## 다시 만들기
```
python -X utf8 build.py            # 만들고 1시간 3회(seed 42, 1, 2) 점검 (2~3분 + 점검 몇 분)
python -X utf8 build.py --no-check
cd verify && python -X utf8 route_check.py   # 카카오 길찾기 결과와 SUMO 경로 비교
```
만드는 도중의 파일(중간 도로망, netconvert 수정 파일, 로그)은 `work/`에 생기고 저장소에는 올리지 않는다.

## 폴더와 파일
| 파일 | 하는 일 |
|---|---|
| `build.py` | 전체 순서: OSM 잘라오기 → netconvert → 수정 파일(신호·주차장·고가·고속도로·높이) → 회전 규칙·교차로 면 → 사거리 신호 → 화면·교통 |
| `config.py` | 지도·로드뷰로 확인한 값: 구현 범위, 일방통행, 신호 갈림목, 유턴 지점, 막힌 캠퍼스 문, 공영주차장 입구 |
| `common.py` | 공통 도우미: 경로(`P` 최종 파일, `W` 중간 파일), netconvert 실행, 꺾은선 계산, 교차로 면 모양(`curb_shape`) |
| `viaduct.py` | 서부로 고가 구간: 고가 엣지, 고가 옆 지상 도로 띄우기, 공영주차장 띠·드나드는 길 |
| `highway.py` | 봉담과천로(축소판 고속도로): 의왕TG 요금소, 휴게소, 청계IC, 학의JC |
| `drawing.py` | 화면: 고가·지하차도 층 도형, 주차장·휴게소·지명, sumo-gui 보기 설정 |
| `traffic.py` | 교통: 고속도로 흐름, randomTrips 일반 차량, 주차 차량, 버스, `skku.sumocfg` |
| `osm_clip.py` | 구현 범위 자르기, 카카오로 확인한 일방통행·차로 수(`LANES_VERIFIED`), 분리 도로 붙이기, 작은 골목 빼기 |
| `parking.py` | 주차 칸(고가 옆 공영주차장, 교내·역 주변)과 주차 차량 (빈 칸이 있는 구역에만 배정) |
| `bus_lines.py`, `bus_kakao.json` | 카카오맵 실제 버스 노선 17개 → 정류장·운행 |
| `background.py`, `campus_poly.json` | 배경(건물·단지·공원·물·철도)과 지명 글자 (sumo-gui 글꼴에 한글이 없어 영어) |
| `view_skku.py`, `run_skku.bat` | 시뮬레이션 보기 (sumo-gui + TraCI, 아래층 차를 반투명하게) |
| `view_av_route.py` | AV 루트 주행 보기: 루트를 달리는 차(주황, SUMO 기본 승용차)를 화면이 따라가고 구간별 배속으로 보여 준다 |
| `osm/` | OSM 원본 (OSM 공식 API로 받은 것) |
| `verify/` | 카카오 길찾기 검증: 구간 목록(`make_checks.py`), 결과·근거(`kakao_routes.txt`, `kakao_verified.txt`), 비교(`route_check.py`) |
| `img/` | 결과 화면, 높이 표현 방안 비교 화면 |
| `skku.*.xml`, `*.rou.xml`, `bg.add.xml` 등 | 만든 결과 (시뮬레이션에 바로 쓰는 파일) |
| `HISTORY.md`, `WORKLOG.md` | 만든 과정과 시행착오, 날짜별 작업 기록 |

## 확인한 것과 가정한 것
- 확인(카카오 길찾기·위성사진·로드뷰): 일방통행, 큰길 차로 수(서부로·덕영대로·화산로·일월로·정자천로 등),
  막힌 캠퍼스 문(후문·서쪽 문), 버스 노선·정류장, 의왕TG·IC 순서
- 사용자 지정: 사거리 보행자 동시신호 45초, 사거리 북쪽 방향(남쪽에서 올라오는 차) 좌회전 금지
- 가정: 사거리 차량 신호 순서·시간 (서부로 직진 50 → 서부로 남행 좌회전 15 → 덕영대로 동행 직좌 15 → 덕영대로 서행 직좌 25 → 보행자 45초)
- 가정: 나머지 신호 교차로 4곳 (build.py korean_plan): 좌회전·직진을 같이 쓰는 차로가 있는 진입로는 방향별 직좌 동시신호,
  없으면 직진 동시 → 좌회전 동시. 우회전은 다른 신호 때도 양보하며. 녹색 2차로 이상 30초, 1차로 18초, 좌회전 15초
- 가정: 교통량, 주차 시간, 요금소 부스 수(한 방향 10개)
- 교통량은 시간대별 배율(traffic.py DEMAND·HW_DEMAND): 처음 10~15분 많이 넣어 대기 줄을 만들고 그 뒤 조금 줄여 쌓인 정도를 유지

## AV 루트 후보 (2026-11-03, 팀 회의에서 정함)
- **제안 (`img/av_route_full.png`, 경로 `verify/av_route_full.json`)**: 위 띠는 고속도로(남행, 구간 순서만), 아래는 실제 지도
  - 고속도로(청계IC 진입 뒤, 가속 차로) → 휴게소 합류 → 의왕TG 요금소(3→10→3차로) → 서부로 (2.9 km)
  - 성대역 사거리 → 고가/지상 분기 → 지상 서부로(버스 정류장, G1) → 올리브영 사거리(G2)에서 오른쪽 골목 → 오거리 3곳 →
    율전로 회전교차로 → 율전로64번길 → 서부로×일월로 보호 좌회전 → 일월로 → 학교 정문 좌회전 (2.4 km)
  - 정문 길 따라 북쪽으로 Modular Bldg 지나 Global Plaza 앞에서 우회전 → 교내 큰 주차장 L1(약 270칸)에 주차·출차 →
    교내 순환로(반시계 일방통행) 한 바퀴 → 정문 (1.9 km)
  - 정문 나가며 좌회전 → 일월로 동쪽 → 일월로 남쪽 끝 도착 (0.5 km). 전체 약 7.8 km, 정문 길 말고는 같은 길을 다시 지나지 않음
  - 다시 만들기: `python -X utf8 verify/route_big.py verify verify/av_route_full.json` → `python -X utf8 verify/draw_combined.py verify/av_route_full.json img/toll_sumo.png img/av_route_full.png`
- 짧은 대안 (`img/av_route.png`, `verify/av_route.json`, 약 2.1 km): 서부로 북쪽 → 성대역 사거리 → 오거리 → 회전교차로 → 서부로×일월로
